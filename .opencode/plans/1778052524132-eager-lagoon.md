# SuperTask npm 发布 — 修复 + 重构计划

> 基于代码审计，当前项目 **不能发布到 npm**。dist/ 中 40 处 `@core/` alias 未解析，任何 import 都会崩溃。

## P0 — 必须修复（否则完全不可用）

### 1. 构建系统：用 tsup 替代 tsc，解决 paths alias 问题

**问题**: `tsc` 不解析 `paths` alias，dist/ 里保留 `@core/` 等裸引用，npm 安装后 ERR_MODULE_NOT_FOUND。

**方案**: 用 `tsup` 构建（bun 生态主流构建工具，内置路径别名解析）。

**文件**: 新建 `tsup.config.ts`，修改 `package.json` scripts

### 2. bin 入口修复

**问题**: `"bin": { "supertask": "./src/cli/index.ts" }` — .ts 不在 files 里。

**方案**: 改为 `"./dist/cli/index.js"`（tsup 输出平铺结构）

### 3. bun:sqlite — 已确认无问题

opencode 是 bun 运行时（源码大量使用 `bun:sqlite`、`bun:ffi`、`bun-pty`）。
加 `engines` 声明即可：`"engines": { "bun": ">=1.0.0" }`

### 4. 消除模块级副作用

**问题**: `import { db } from '@core/db'` 立即创建数据库连接。

**方案**: 改为 lazy init 模式：
```ts
let _db: ReturnType<typeof drizzle> | null = null;
export function getDb() { if (!_db) _db = initDb(); return _db; }
```

## P1 — 严重问题

### 5. migrate.ts 路径修复

### 6. 依赖管理修复

### 7. gateway/index.ts 导出 main 函数

去掉顶层 `main()` 调用，改为 `if (import.meta.main) main()`。
