# SuperTask 项目分析

> 最后更新：2026-05-06

## 项目概览

**OpenCode SuperTask (OST)** — 基于 SQLite 的高性能任务队列管理系统，专为 OpenCode Agent 设计。支持批量创建任务、管理依赖关系，通过后台 Worker 自动调度 Agent 执行。

- **版本**: 0.1.0
- **作者**: javazys
- **许可证**: MIT

## 技术栈

| 维度 | 选型 |
|------|------|
| 运行时 | Bun（内置 SQLite 驱动 `bun:sqlite`） |
| 语言 | TypeScript 5.9.3 (ESM) |
| ORM | Drizzle ORM 0.39.1 + drizzle-kit 0.30.4 |
| 数据库 | SQLite（`~/.local/share/opencode/tasks.db`） |
| Web 框架 | Hono 4.7.4 + JSX (SSR) |
| CLI 框架 | Commander 13.1.0 |
| 插件 SDK | @opencode-ai/plugin ^1.1.42 |
| 构建工具 | tsc |

## 架构

### 四入口 + 三层

```
┌───────────────────────────────────────────┐
│  入口层（CLI / Worker / Web / MCP Plugin） │
├───────────────────────────────────────────┤
│  服务层（TaskService / TaskRunService）     │
├───────────────────────────────────────────┤
│  数据层（Drizzle ORM + bun:sqlite + WAL）  │
├───────────────────────────────────────────┤
│  SQLite 文件（~/.local/share/opencode/tasks.db）│
└───────────────────────────────────────────┘
```

- **无依赖注入**：服务层全部使用静态类方法，直接导入 db 实例
- **项目隔离**：按 `cwd` 字段区分不同项目的任务
- **乐观锁并发安全**：`TaskService.start()` 用 WHERE 条件抢占，多 Worker 安全

## 数据库 Schema

### tasks 表（主任务）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | integer PK | 自增主键 |
| name | text NOT NULL | 任务名称 |
| agent | text NOT NULL | 执行的 Agent 名称 |
| model | text | 模型（默认 default） |
| prompt | text NOT NULL | 发给 Agent 的提示词 |
| cwd | text | 工作目录（项目隔离） |
| category | text | 分类：translate/test/generate/review/general |
| importance | integer | 重要程度 1-5（默认 3） |
| urgency | integer | 紧急程度 1-5（默认 3） |
| batchId | text | 批次 ID |
| dependsOn | integer | 依赖的任务 ID |
| status | text | pending/running/done/failed/cancelled |
| createdAt / startedAt / finishedAt | integer | 时间戳 |
| resultLog | text | 结果日志 |
| retryCount | integer | 已重试次数（默认 0） |
| maxRetries | integer | 最大重试次数（默认 3） |

### task_runs 表（执行记录）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | integer PK | 自增主键 |
| taskId | integer FK → tasks.id | 关联任务 |
| sessionId | text | opencode session ID |
| model | text | 实际使用的模型 |
| status | text | running/done/failed |
| startedAt / finishedAt | integer | 时间戳 |
| log | text | 执行日志/错误信息 |

## 核心流程

### Worker 执行流程

```
while(true) {
  1. TaskService.next()         → 获取任务（优先可重试 failed > pending，FIFO）
  2. TaskService.start(id)      → 乐观锁抢占
  3. TaskRunService.create()    → 创建执行记录
  4. spawn("opencode run --agent supertask-runner -m <model>")
  5. 解析 sessionId → updateSessionId()
  6. 根据退出码 → done() / fail()
  7. 无任务时 sleep 5s
}
```

### 任务调度策略

- 优先级：可重试 failed > pending
- 排序：createdAt ASC（先进先出）
- 依赖检查：dependsOn 指向的任务必须为 done
