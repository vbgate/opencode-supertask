## 项目概览

**OpenCode SuperTask (OST)** — 基于 SQLite 的高性能任务队列管理系统，专为 OpenCode Agent 设计。Gateway 常驻进程集成 Worker/Scheduler/Watchdog，支持定时调度、心跳检测、自动重试、过期清理。

- **版本**: 0.1.0
- **作者**: javazys
- **许可证**: MIT

### Gateway 架构

```

├── Worker         → 并发池，spawn supertask-runner，心跳上报
├── Scheduler      → 定时克隆模板任务（cron/delayed/recurring）
└── Watchdog       → 心跳超时检测 + 指数退避重试 + 过期清理
```

## 数据库 Schema

### tasks 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | integer PK | 自增主键 |
| name / agent / model / prompt / cwd | text | 任务配置 |
| category | text | translate/test/generate/review/general |
| importance / urgency | integer | 优先级 1-5 |
| batchId / dependsOn | text/integer | 分组与依赖 |
| status | text | pending/running/done/failed/dead_letter/cancelled |
| createdAt / startedAt / finishedAt | integer (timestamp) | 秒级时间戳 |
| retryCount / maxRetries | integer | 重试控制 |
| retryAfter | integer | 退避截止时间（毫秒） |
| timeoutMs / templateId / scheduledAt | integer | Gateway 扩展 |

### task_runs 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id / taskId / sessionId / model / status | 基础字段 | 执行记录 |
| startedAt / finishedAt | integer (timestamp) | 秒级时间戳 |
| log | text | 执行日志 |
| lockedAt / lockedBy / heartbeatAt | integer | 毫秒时间戳 |
| workerPid / childPid | integer | 进程 PID |

### task_templates 表

| 字段 | 类型 | 说明 |
|------|------|------|
| scheduleType | text | cron / delayed / recurring |
| cronExpr / intervalMs / runAt | 调度参数 | 按类型使用 |
| maxInstances / maxRetries / retryBackoffMs | integer | 并发与重试控制 |
| lastRunAt / nextRunAt | integer (ms) | 运行状态 |
| enabled | integer (boolean) | 开关 |

## 核心流程

### Gateway 启动

```
1. acquireLock()           → SQLite BEGIN IMMEDIATE 进程锁
2. 加载配置                 → ~/.config/opencode/supertask.json
3. Worker.start()          → poll 轮询 + 心跳上报
4. Scheduler.start()       → 初始化模板 nextRunAt + tick 定时检查
5. Watchdog.start()        → 心跳超时检测 + 过期清理
6. 监听 SIGTERM/SIGINT     → 优雅退出
```

### Worker 执行流程

```
poll() → tryDispatch() 循环:
  1. TaskService.next({ excludedBatchIds })  → 排除同 batchId 的运行中任务
  2. TaskService.start(id)                   → 乐观锁抢占
  3. TaskRunService.create() + updatePid()   → 创建执行记录
  4. spawn("opencode run --agent supertask-runner ...")
  5. 解析 sessionId → updateSessionId()
  6. 退出码 → done() / fail()（含指数退避 + dead_letter）
```

### 任务调度策略

- 优先级：urgency DESC → importance DESC → createdAt ASC
- retryAfter 过滤：未到退避时间的 failed 任务不参与调度
- batchId 隔离：同 batchId 任务串行，不同 batchId 并发
- null batchId 任务允许并发（不互斥）

### 重试机制

- 统一 `computeBackoff(retryCount)`: `30000 * 2^(retryCount-1)`，上限 30 分钟
- retryCount 达到 maxRetries → dead_letter
- 手动 `retry` 可重置 dead_letter 任务

## API 汇总

### CLI 命令

`add` / `next` / `start` / `done` / `fail` / `cancel` / `retry` / `status` / `list` / `get` / `delete` / `template add/list/enable/disable/delete`

### Web HTTP API（端口 3000）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | Dashboard 页面 |
| GET | `/api/tasks/:id` | 任务详情 |
| POST | `/api/tasks/:id/retry` | 重试任务（支持 failed/dead_letter） |
| DELETE | `/api/tasks/:id` | 删除任务 |
